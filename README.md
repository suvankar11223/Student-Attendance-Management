🎓 Student Attendance Management System
✨ Empowering Education with Intelligent Attendance
This project revolutionizes traditional attendance tracking by leveraging advanced Face Recognition technology. Built with Python, OpenCV, and MySQL, it offers a seamless, automated, and secure system for managing student attendance in real-time. Say goodbye to manual roll calls and hello to efficiency!

🛠️ Technologies Used
Python 3.8+: The core programming language.

OpenCV 4.x: For robust face detection and recognition.

MySQL 5.7+: For reliable database storage of student and attendance records.

Tkinter: For the intuitive and functional Graphical User Interface.

Pandas: For efficient data processing and Excel/CSV report generation.

mysql-connector-python: For Python-MySQL database interaction.

Pillow: For image manipulation within Tkinter.
